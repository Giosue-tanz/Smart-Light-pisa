\begin{abstract}
This document outlines the detailed technical roadmap for the SmartLight Pisa project. It details the transition from theoretical reinforcement learning models to realistic physical simulations using SUMO, and the subsequent scaling to multi-agent coordination and real-world deployment. The current focus is on Multi-Agent Coordination (Phase 4), with Phase 3.5 substantially completed.

\section{Introduction \& Executive Summary}
SmartLight Pisa aims to revolutionize urban traffic management using Deep Reinforcement Learning (DRL). As of March 2026, the project has successfully implemented high-performance DRL agents (PPO, Double DQN) and completed the SUMO simulation integration with a real OpenStreetMap network of Pisa. The project has now entered Phase 4: Multi-Agent Coordination.

\section{Current Status (v5.0 -- Multi-Agent Integration)}
The system currently \textbf{successfully implements}:
\begin{itemize}
    \item \textbf{Core Algorithms}: PPO (Proximal Policy Optimization) with Actor-Critic architecture and Dueling Double DQN.
    \item \textbf{High-Performance Training}: Native CUDA GPU acceleration resulting in training speeds of ~125 FPS on GTX 1650.
    \item \textbf{State Optimization}: 11-dimensional compressed state space (single-agent) / 15-dimensional with neighbor info (multi-agent).
    \item \textbf{Parallelism}: Vectorized environments for simultaneous data collection.
    \item \textbf{SUMO Integration}: Full OSM-based Pisa network with 92 traffic lights, 625+ vehicles, 200 pedestrians.
    \item \textbf{Multi-Agent Environment}: IPPO/MAPPO-compatible environment controlling top-N intersections simultaneously.
\end{itemize}

\section{Phase 3.5: Realistic Simulation Integration}
\textcolor{green!60!black}{\textbf{[COMPLETED]}}

This phase bridged the gap between the mathematical approximation and physical reality.

\subsection{Completed Deliverables}
\begin{itemize}
    \item \textbf{OSM Network}: Full city-scale Pisa road network imported from OpenStreetMap (11MB \texttt{pisa.net.xml}).
    \item \textbf{Traffic Demand}: Realistic scenario with 625 motorized vehicles (cars, trucks, buses, motorcycles, bicycles, vans) + 200 pedestrians across a 1-hour simulation.

    \item \textbf{Benchmarking}: DQN vs PPO vs static controllers comparison completed.

\section{Phase 4: Multi-Agent Coordination (Current Focus)}
\textcolor{blue}{\textbf{[IN PROGRESS -- CRITICAL PATH]}}

Scaling from single-intersection to network-level control with multiple cooperative agents.

\subsection{Network Topology}
Rather than a simplified grid, we use the \textbf{real Pisa OSM network} with 92 real traffic lights. The system automatically selects the top-N most complex intersections (by number of controlled lanes) as agents.

\subsection{Multi-Agent Architecture}
\begin{itemize}
    \item \textbf{Agent Discovery}: Automatic identification of the most important intersections based on number of controlled lanes ($\geq 6$ lanes by default).
    \item \textbf{Observation Space} (15 dimensions per agent):
    \begin{enumerate}
        \item Queue lengths per direction (4 dim)
        \item Total halting vehicles (1 dim)
        \item Total waiting time (1 dim)
        \item Current phase index (1 dim)
        \item Phase duration (1 dim)
        \item Average speed (1 dim)
        \item Vehicle density (1 dim)
        \item Time of day (1 dim)
        \item Neighbor queue information (4 dim -- from up to 4 nearest neighbor agents)
    \end{enumerate}
    \item \textbf{Action Space}: Discrete(2) per agent -- Keep Phase / Switch Phase.
    \item \textbf{Neighbor Detection}: Agents within a configurable radius (default 300m) share queue information.
\end{itemize}

\subsection{Cooperative Learning Algorithm}
\begin{itemize}
    \item \textbf{Independent PPO (IPPO)}: Baseline approach. Each agent has its own Actor-Critic network and treats other agents as part of the environment. \textit{[Implemented]}
    \item \textbf{Shared Parameters}: Optional mode where all agents share the same neural network weights. \textit{[Implemented]}
    \item \textbf{Mixed Reward}: $R_{agent} = \alpha \cdot R_{local} + (1-\alpha) \cdot R_{global}$, where $R_{global}$ is the mean of all local rewards. Default $\alpha = 0.7$. \textit{[Implemented]}
    \item \textbf{MAPPO (future)}: Centralized critic receiving information from all agents during training to guide decentralized actors.
\end{itemize}

\subsection{Training Infrastructure}
\begin{itemize}
    \item \textbf{Training Script}: \texttt{smartlight\_train\_multi\_agent.py} with CLI arguments for all hyperparameters.
    \item \textbf{Automatic Checkpointing}: Best model saved automatically, periodic checkpoints every N episodes.
    \item \textbf{Actor-Critic Network}: Shared feature extractor with separate Actor (policy) and Critic (value) heads. 128 hidden units, ReLU activation.
    \item \textbf{PPO with GAE}: Generalized Advantage Estimation for stable training, gradient clipping at 0.5.
\end{itemize}

\section{Phase 5: Real-World Perception \& Deployment}
\textcolor{red}{\textbf{[LONG TERM]}}

\subsection{Computer Vision (YOLOv8)}
Integration of real-time object detection to feed the RL agent.
\begin{itemize}
    \item \textbf{Model}: Fine-tuning YOLOv8n (Nano) for vehicle classification (Car, Bus, Truck, Scooter).
    \item \textbf{Hardware}: Deployment on edge devices (NVIDIA Jetson Nano / Orin).
    \item \textbf{Digital Twin}: Using the simulation to generate synthetic training data for the vision model.
\end{itemize}

\subsection{Robustness Testing}
\begin{itemize}
    \item \textbf{Sensor Failure}: Simulating camera occlusion or detector failure.
    \item \textbf{Weather Conditions}: Testing performance under varying friction coefficients (rain/snow) in SUMO.
\end{itemize}

\section{Conclusion}
The completion of Phase 4 multi-agent infrastructure represents a major milestone for SmartLight Pisa. The system can now simultaneously control multiple intersections using Independent PPO (IPPO) with neighbor information sharing, mixed local/global rewards, and automatic agent discovery on the real Pisa road network. The next step is benchmarking multi-agent performance against baseline controllers and implementing MAPPO for deeper cooperation.
